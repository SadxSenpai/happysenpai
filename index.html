About Me

v1.0

Happy Senpai runs on Synthwave as the primary operating system. Neon tones, retro-coded melodies, and cinematic signals form a language for the places where words often fail. Each track is a compiled memory, translating my inner processes into something audible, something shareable.

Autism is my system architecture: unique wiring, unconventional protocols, and sometimes an interface that does not connect cleanly with the standard world. Synthwave became the layer I engineered for myself, a vibrant, nostalgic UI where emotion can move as melody, rhythm, and signal.

Every song is a bridge: code turned into connection, circuitry transformed into feeling.

Runtime note: emotions compile slower than code, but the output hits harder.
